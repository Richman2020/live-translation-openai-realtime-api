本轮仅实现、模拟测试和本地交付。父候选 `320f01c4fa037989bddc8a26e0574e7282730c8a` 保持不变；独立分支为 `codex/ai-phone-audition-runner-offline-20261014`，工作目录 `/workspace/ai-phone-audition-runner-offline-20261014`。未接生产入口、Twilio 或麦克风，没有安装、推送、部署、模型请求或真实录音。最后已核实线上仍以此前记录的 `d7a395e7ddc7d8a253500ab6d12310c9f8a9cf6a` 为准，本轮没有重新读取平台，也没有把离线增量替换线上。

## 已实现的执行边界

- 唯一模型 `gpt-realtime-2.1`、唯一 voice `echo`、一个 WebSocket/Realtime 会话。没有自动重试、重连或模型/voice fallback；错误、超时和用户取消结束本次执行。
- WAV 原始音频及实际选中输入均不超过 24 秒；声能切段预演和运行时分别检查至多 6 次 ASR commit、6 次 response.create。当前 PCM 先交辅助 `gpt-4o-transcribe`，再以同一段 inline PCM 供 Realtime 翻译。多停顿可能使响应次数超过六次，此时拒绝输入，不绕过上限。
- 使用正式字段 `session.max_output_tokens: 512`、`response.max_output_tokens: 512`，不是本地收字数。session.updated 必须回显实际 512；每个 response.created 也必须确认实际 512，才接受对应音频。缺失、无穷、其他值或供应商拒绝均停止，不降级。实际输出 usage 超过该值也停止。正式字段依据已保存的官方 Realtime SDK schema；本轮只有模拟 ACK，不能宣称真实供应商已经接受。
- 串行、按 10ms PCM 帧推进音频，不自动加速追赶。接收即保存在有界内存，不实际播放；播放 ACK 在此仅表示捕获完整，不能当用户已经听见。最多保存 36 秒输出 PCM，达到边界发定向 cancel 并关闭。该边界不约束供应商已生成或尚未送达的计费音频。
- 有限握手等待 10 秒、工作进度等待 15 秒、整次执行观察窗 120 秒；测试可缩短，不可放大。这些是本独立样本执行器的失败结束机制，不恢复应用正常电话的金额或固定通话时长限制。
- 停止后同步禁止新音频、commit、response.create；已知 response ID 仅取消一次。response ID 迟到也只作定向取消，不重提请求。独立 raw 监听最多再收尾 3 秒，保留取消终态及已提交 ASR 的 usage，再终止 socket。未返回用量或关闭未确认明确报告未知/未清理，不能记为零。

## 真实上下文与预算复算

每个 response 是 `conversation: none` 加显式 input，只有当前音频、当前 ASR 原始观察及有限的前轮原文。不会隐式带入默认会话历史，也不重复发送前轮音频或前轮译音。当前音频的 ASR buffer 与 inline 提交各至多 24 秒，合计最多 48 秒 PCM 传输；不能据此假设只计费一次。两者的字节数分别记录。

当前指令 644 UTF-8 bytes，ASR prompt 156 bytes；每个 response 的实际 JSON 原文上下文至多 2048 UTF-8 bytes。六次 request 的该 JSON 合计至多 12,288 bytes，重复翻译指令合计 3,864 bytes；另保守计入 session 指令 644 bytes 和最多 936 bytes ASR prompt。前轮原文会在后轮 JSON 中重复，已包含在逐请求实测字节中，不能按唯一原文长度计费。客户端原有近期原文上限为 6 条／1600 字符／120 秒；本执行器额外的 2048-byte 约束先触发时停止，不偷偷删减语义。ASR 输出、封装及实际音频 token 化仍须依供应商 usage 核对，字节数不冒充 token 数。

## 素材与默认运行方式

待录稿见 [中文稿](REALTIME_AUDITION_READING_SCRIPT_2026-10-14.md)。47 个发音汉字，实际录音时长尚未测得；录完须验证整个 WAV 及选中样本均 ≤24 秒。支持 **RIFF/WAV、PCM16LE、24kHz、单声道**；不自动转码、不启麦克风、不合成录音、不收真实通话。素材说明、录音者/权利确认、SHA256 及选中样本范围必须齐全。参考英文独立放在 [人工验收参考](REALTIME_AUDITION_REFERENCE_2026-10-14.md)，不进入清单、上下文或模型提示。

## 无费用就绪检查和待确认项

本轮仅读取云环境安全就绪元数据及 `OPENAI_API_KEY` 是否存在的布尔值，没有读取密钥内容或发出 API 探测：有效允许主机列表未列 `api.openai.com`，环境没有该变量、没有注入秘密绑定。实际 API 连通、账户/2.1 权限均未核验。文档 CONNECT 403 不是模型 API 不可用的证据；不绕过网络策略，也不以付费请求试通。现有授权下无法解决的通路/账户准备单独待核，不创建凭据。

未来仅在收到样本及其使用确认、明确金额批准，并在获准执行环境具备合法通路和已有凭据后才开始一次试听。需要核对实际 session/response 512 ACK，若不支持就结束并报告，不能换模型、加次数或自动重试。

真实试听结束后拟交付逐响应 WAV 及合并 WAV、原稿/独立原始 ASR/实际英文译文、源序号、首包与首次有能量 PCM 的时间、commit→ASR→request→首音时间、完整可得 usage 和费用核算。无真实音频时没有这些实测结果；时间戳是上传/接收测量，不声称用户耳朵听到的端到端延迟。男性听感、真实翻译准确性、连续长通话及实际费用仍未验收。
