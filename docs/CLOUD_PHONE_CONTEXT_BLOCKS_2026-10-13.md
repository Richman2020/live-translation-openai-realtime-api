## 上下文、整理和修订

每通独立内存；每方最多 4 个不同来源、每来源 2 个版本。单条完整原文或完整自然句摘录最多 600 字符；快照最多 6 条 / 1600 原始字符 / 120 秒。超长原文带尚未完成的尾巴时保守省略整个来源，避免只取先前完整句而丢掉尾巴中的更正；无安全完整句也省略，不截断金额、日期、地址或否定。结束清空，不持久保存正文、不新增正文日志。

上下文标记 role、ASR/native source/native generated、原始顺序、版本及观察时间。当前来源开始时可见的临时/生成文本冻结；后到的前文 ASR final 只有可信 stop/commit 边界严格早于当前来源开始才可纳入，不能以 completed 到达时间冒充发言结束。当前数字、日期、地址、否定、更正优先；证据不足时要求明确不确定，不让模型凭上下文补事实。提示约束不等于模型效果已实测。

原始 `text` 保留，另设 `displayText/normalization=conservative`。仅有限的精确相邻口吃重复整理；保留可能有语法、强调、否定、数字、地址、自我更正意义的重复。界面可展开核对识别原文，翻译输入明确带原文及整理文本差别。没有把生成或整理文本标成“实际听到的原话”。

ASR 提示变更至少间隔 5 秒、无 active speech、只允许一个 pending ACK，加入最多 1200 原文上下文字符。只对精确匹配可选提示更新的受限 schema 拒绝回退到既有 ASR 基线；身份、额度、泛化错误不吞掉。固定状态 baseline/pending/active/unsupported 及数值计数不包含原文、提示或原始供应商异常；active 仅表示配置 ACK。

文字请求最多增加 1600 上下文字符、原有 800 前文字符和必要的原始文本对照（原有单条上限 4096）；JSON 转义、固定指令及元数据另计。不是 token 或费用保证。没有因上下文更新增加 session 或 response.create，没有新增翻译请求调度；文字输入 token 与 ASR 提示可能增加费用，实际用量与延迟本轮未测量。5 秒是提示节流，不是通话或播放时限。

## 连续对话块与安全边界

只有有效原文（Unicode 字母或数字）建立说话方边界。同一方来源按原始顺序追加同一外层块，自然小节成为内部段落；供应商 completed、短暂停顿及文字翻译本身不新建大块。另一方有效原文到来后建立新块；A→B→A 保持三块。迟到已知来源按原时序修正原块，不按结果到达顺序插入；缺来源的译文不抢占当前说话方。

正文版本、翻译对应 sourceRevision 与独立分组 epoch 各自校验。更高来源版本可增量替换旧中文；新中文尚未对应新原文时隐藏旧译文，避免金额/否定错配。最终空白/纯标点原文会撤回该来源及其旧译文，撤回记录保留版本围栏，不能被旧迟到文本复活；新有效来源修订可按原位置恢复。

分组注册表和 adapter 缓存均有 1024 来源上限，超过后保守冻结旧绑定，不把旧来源接到当前块；此限额不挂断通话。显示分组只在 phone controlled 页面启用；旧非 phone 页面保留原模式。中文阅读区与挂断按钮保持。分组与音频发出、重采样、播放队列完全解耦，不为等待整块而拖延译音。

新增 UI 绑定补发仍逐步复核 live admission；订阅方同步挂断/退出后不再续发本通更新。身份认证、供应商验签、控制权、多标签隔离、单通、手动和远端挂断、真实失联清理没有放宽。独立审查发现版本元数据回退、旧翻译错配、上下文同文本高版本未推进围栏、空 final 幽灵边界及超长来源摘录丢失末尾更正五项问题；修前红/修后绿及最终独立核验见进度记录。它们不是本次真人识别或听感事故的已证实原因。
